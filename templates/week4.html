Web Scraping using Python

Static • Dynamic • REST API Data Collection

During Week 4 of my internship, I explored different techniques for collecting data from websites and online services. I learned Static Web Scraping using Requests and BeautifulSoup, Dynamic Web Scraping using Selenium for JavaScript-based websites, and API Data Collection using REST APIs with JSON responses. These techniques enabled me to build real-world data acquisition projects and integrate them into Flask applications.

Web Scraping Categories

Explore the three major approaches to collecting data using Python.

Static Scraping

Extract information from static websites using Requests and BeautifulSoup. Ideal for websites where the HTML content is available immediately without JavaScript execution.

Learn Static

Dynamic Scraping

Scrape JavaScript-based websites using Selenium and browser automation. Interact with buttons, forms, and dynamically loaded content.

Learn Dynamic

API Scraping

Collect structured information using REST APIs, JSON responses, authentication, and HTTP requests for reliable data access.

Learn API
